# 电煤库存联动调度

本项目服务于联结煤矿、电厂库存和铁路运力的保障计划。仓库保存领域资料、交换契约和可运行的服务入口，便于参与方在同一语义下协作。

## 领域事实

- 铁路加大主产区煤炭外运力度
- 电煤运输强调应装尽装
- 直供电厂存煤保持较高水平
- 局部线路检修、煤矿减产或连续高温可使区域库存迅速跌破安全天数

`docs/domain-rules.md` 将调度要求整理为规则 R1–R10，覆盖滚动计划、紧急倾斜、预测修订边界、数量守恒、幂等报送、三方确认、双人批准、指令恢复、值班员视图与审计可解释。

## 目录说明

- `contracts/` 保存交换数据的结构约定，含领域上下文与环节数量报送契约。
- `fixtures/` 提供去标识的领域样例，含一批煤跨环节报送示例。
- `docs/` 保存领域规则说明。
- 源码目录提供资料读取、数量守恒核对与健康检查入口。
- `tests/` 核对领域资料能够被稳定载入，并验证幂等报送与数量守恒。

## 本地检查

运行 `npm test` 可以检查当前资料与服务入口。
