# 调度领域规则

本文件把迎峰度夏期间的保障要求整理为可核对规则，编号 R1–R10 供测试与审计引用。

## R1 滚动计划

- 计划按日滚动编制，汇总：电厂日耗与库存、煤矿可装量、线路能力、车底周转、高温影响、既有合同。
- 高温影响体现为日耗上修与线路能力下调的调整因子。
- 既有合同是计划的硬约束，非紧急倾斜不得削减。

## R2 紧急倾斜

- 触发条件：区域或电厂库存预计跌破安全天数。
- 每次倾斜必须记录：触发阈值、触发时的输入快照、被挤占订单（订单号、挤占量、原定区间与调整后区间）。
- 倾斜顺序须兼顾民生与既有合同，不得简单按先来先装。

## R3 预测修订边界

- 预测修订仅作用于尚未执行的区间。
- 已执行区间冻结，作为审计基线，不得回改。

## R4 数量守恒

- 同一批次：装车量 = 到厂量 + 退运量 + 在途未结量。
- 到厂量与退运量之和不得超过装车量，超出部分即为虚假库存。

## R5 幂等报送

- 每条环节报送携带唯一 `report_id`，重复报送按首次到达去重。
- 跨时区晚到数据按 `occurred_at`（须含时区偏移）归属计划区间，不得按到达时间重复计入库存。

## R6 三方确认

- 矿区确认装车，铁路确认在途与退运，电厂确认到厂。
- 确认记录由责任方各自签署，不可由其他方代签。

## R7 双人批准

- 重大人工改序（改变已下达计划的优先级或路径）须两名授权人先后批准。
- 批准记录包含双方身份、时间与理由。

## R8 指令恢复

- 未完成指令持久化保存。
- 系统重启后按持久化状态恢复执行，不重复下达、不丢失。

## R9 值班员视图

- 及时展示未来数日的缺口、可行替代方案及其影响范围（波及订单与区域）。

## R10 审计可解释

- 每次优先保障可由记录回放：触发阈值、输入快照、被挤占订单与批准链。
- 审计人员据此解释每次优先保障为何成立。
